# v0.4.0 — Backup Reliability Release

This release delivers a complete, automated, and self-maintaining backup workflow for the PVS6 monitoring system. It focuses on reliability, data integrity, and long-term operational stability.

---

## Summary
The backup system now automatically:
- Creates nightly system + database backups
- Compresses backup archives
- Enforces a configurable retention window
- Validates backup integrity using checksums
- Rotates and cleans backup logs

These improvements significantly enhance system resilience and reduce manual maintenance.
